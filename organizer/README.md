# Официальные файлы кейса

Эта папка содержит неизменённые файлы из выданного участникам пакета **Beeline Tariff Marketing Campaigns Case**. Они отделены от реализации BeeSmart и не содержат CSV организаторов.

| Файл | Назначение |
|---|---|
| `environment.py` | Публичный контракт среды и выполнение пилотов |
| `mock_environment.py` | Локальная среда с синтетическими эффектами |
| `scoring_core.py` | Подсчёт результата и ограничения кампаний |
| `local_eval.py` | Локальная оценка агента |
| `make_submission.py` | Создание воспроизводимого плана с seed 42 |
| [PARTICIPANT_GUIDE.md](PARTICIPANT_GUIDE.md) | Условия и инструкция организаторов |

Официальные Python-файлы используют плоские импорты и относительные пути к CSV. Интеграция BeeSmart настраивает их поиск до перехода в каталог конкретного набора данных. Сам агент находится в `beesmart/agent/`, а корневой `agent.py` сохраняет контракт `Agent.act(env)` для судейства.

`scripts/build_submission.py` копирует эти пять Python-файлов без изменений в корень приватного экспортируемого пакета, сохраняет пакет агента и точную `policies/frozen_policy.json`, запускает официальный генератор и сравнивает полученный CSV с выбранным API-запуском. Данные, отчёты, политики OpenAI и экспортируемые пакеты хранятся вне Git. Команды запуска находятся в [README проекта](../README.md).
